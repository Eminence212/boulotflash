# Pages légales publiques (OAuth)

Pages HTML statiques pour remplir les URL **Branding** Google / Meta tant que la PWA n’est pas déployée.

| Fichier | URL cible une fois hébergé |
| --- | --- |
| `index.html` | `https://<hôte>/` ou `…/index.html` |
| `confidentialite.html` | `https://<hôte>/confidentialite.html` (ou réécrire vers `/confidentialite`) |
| `conditions.html` | `https://<hôte>/conditions.html` (ou `/conditions`) |

Publier ce dossier sur un hôte HTTPS, puis reporter les URL dans [AUTH_OAUTH_PROVIDERS.md](../AUTH_OAUTH_PROVIDERS.md) §3.2.1.

Sources : [POLITIQUE_CONFIDENTIALITE.md](../POLITIQUE_CONFIDENTIALITE.md), [CONDITIONS_UTILISATION.md](../CONDITIONS_UTILISATION.md).
